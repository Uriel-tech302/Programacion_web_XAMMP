# Actividad 1 - Programación Web en XAMMP

**Autor:** Uriel Espinoza de la Rosa

## 📋 Descripción
Este repositorio contiene los 18 ejercicios prácticos realizados durante la Actividad 1 de la materia de Programación Web. El proyecto tiene como finalidad organizar todos los trabajos en un solo sitio web, facilitando su consulta mediante una página principal (`index.html`) que funciona como menú de navegación.

## 🎯 Objetivos
*   Integrar los ejercicios prácticos en un repositorio público estructurado mediante carpetas.
*   Reforzar el uso de rutas relativas para enlazar correctamente páginas, estilos, scripts e imágenes.
*   Aplicar HTML5 para la estructura, CSS3 para el diseño visual y JavaScript para las validaciones e interacción.
*   Publicar el proyecto completo y funcional mediante GitHub Pages.

## 💻 Tecnologías Utilizadas
*   HTML5 & CSS3
*   JavaScript
*   XAMPP (Servidor local)
*   GitHub & GitHub Pages

## 🚀 Resumen de mis prácticas

En este repositorio he ido construyendo mi aprendizaje de Desarrollo Web paso a paso. Aquí detallo lo que hice en cada ejercicio:

* **Ejercicio 1:** Se creo la primera página web con el texto "Hola Mundo", alojándola en XAMPP y aplicando la estructura básica de HTML5.
* **Ejercicio 2:** Practiqué el formato básico de texto usando etiquetas semánticas para párrafos, negritas, énfasis y saltos de línea.
* **Ejercicio 3:** Agregué enlaces simples para poder navegar entre mis diferentes prácticas y hacia sitios web externos.
* **Ejercicio 4:** Inserté imágenes en mi página web configurando correctamente sus rutas, dimensiones y textos alternativos.
* **Ejercicio 5:** Integré los conocimientos anteriores creando una página de blog personal que combina texto estructurado, una foto y enlaces.
* **Ejercicio 6:** Organicé el contenido de mi página usando etiquetas semánticas de HTML5, incluyendo cabeceras, secciones y un pie de página.
* **Ejercicio 7:** Estructuré los ingredientes y pasos de una receta de tacos al pastor utilizando listas ordenadas y desordenadas anidadas.
* **Ejercicio 8:** Diseñé mi horario de clases creando una tabla de datos completa (`<thead>`, `<tbody>`) y dándole todo el diseño visual con CSS.
* **Ejercicio 9:** Construí un formulario de contacto con diferentes tipos de campos de entrada y le apliqué un diseño profesional usando variables de CSS.
* **Ejercicio 10:** Desarrollé una pequeña calculadora interactiva con JavaScript que captura un valor y convierte grados Celsius a Fahrenheit al presionar un botón.
